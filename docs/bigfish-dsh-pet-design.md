# 设计：bigfish 桌宠替代（依附启动器）· 2026-08-16

## 目标
以 bigfish（dafeiyu-pet, PySide6, MIT）完整代码为桌宠基底，加入我们的 DSH 集成提升；
启动器为主体（保留全部功能），鲸鱼娘依附于启动器（启动器拉起/退出）。

## 架构
- `dsh-whale-pet.py`（新）：bigfish 改造版桌宠，独立 python 进程
- `dsh-launcher.ps1`：主体（DSH 管理面板+服务管理+托盘+单实例），删 WPF 桌宠引擎，改为进程管理

## bigfish 代码改造
- 删：CPU/内存/GPU 监控（psutil/pynvml）、5 食物→2 食物（🐟🍰）
- 保留：三视图程序动画/拖拽/双击喂食/单击功能面板/右键全套/聊天框/气泡/天气/托盘/穿透/置顶/自启/config
- 新增（我们的提升）：
  1. DSH 会话联动：轮询 ~/.dsh/sessions（15s 内写入=忙）→ 思考动作+台词；忙完>20s → 庆祝
  2. 右键菜单 DSH 控制：▶ 打开 DSH（PWA 优先）/ ↻ 重启 DSH（taskkill 进程树）/ 🔧 装配环境（检测 node/npm/dsh → npm i -g）
  3. 单实例 + 无控制台启动（pythonw）

## 启动器改造
- 删：WPF 桌宠引擎（三视图/气泡/台词/交互/菜单/托盘桌宠项）
- 加：BtnPetToggle → 拉起/关闭 python 桌宠进程；启动时自动拉起；退出时杀进程
- 保留：主界面/环境/技能/装配面板、服务管理、托盘（自启/穿透）、vbs 无控制台、PWA 启动

## 验收
- 启动链路：快捷方式 → 启动器 → 桌宠自动出现
- 桌宠：拖拽/双击喂食（2食物）/右键全套/聊天框/天气/DSH 联动/DSH 控制菜单
- 启动器：打开/重启/装配/面板全保留；退出时桌宠同退
